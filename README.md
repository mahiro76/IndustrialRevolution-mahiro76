# Industrial Revolution Mod

## Introduction
This is an open-source industrial-themed mod for Minecraft 1.20.1, tentatively named "Industrial Revolution". It aims to enrich the game with a variety of industrial machines and automation content.

## Notice
**This mod is still in early development and may be unstable. If you encounter any issues, please report them via [Issues](../../issues).**
**Support for Minecraft 1.21.1 has been temporarily suspended.**

## Features
- Multiple industrial machines and automation devices
- Energy systems and resource processing
- Extensible modular design

## Usage
- For detailed gameplay and recipes, please refer to the [Wiki](./Wiki) or in-game documentation.
